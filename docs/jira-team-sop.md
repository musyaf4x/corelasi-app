# Jira Team SOP

## Status minimal
- To Do
- In Progress
- Done

## Format comment minimal
- selesai:
- evidence:
- blocker/dependency:
- handoff ke:

## Sprint rule
- sebelum start sprint: cek acceptance criteria, owner, dan scope
- saat sprint berjalan: gunakan board untuk standup
- akhir sprint: hanya yang benar-benar selesai masuk `Done`
